# Exercise 5.5 — Platform comparison

## Submission answer

- I choose **Rancher** over **OpenShift**.
- Rancher centrally manages many CNCF-certified Kubernetes distributions, including GKE, EKS, AKS, RKE2, and K3s. That makes it a strong fit for heterogeneous clusters.
- OpenShift is a broader, more opinionated application platform. It integrates developer tooling, GitOps, pipelines, serverless, service mesh, observability, security features, and commercial support.
- OpenShift is attractive when an organization wants one standardized platform and workflow. Rancher is better when existing Kubernetes choices should remain intact.
- This course used both GKE and k3d/K3s. Rancher's distribution-neutral management therefore provides more immediate value, less migration pressure, and greater infrastructure freedom for this environment.

Sources: [SUSE Rancher Prime](https://www.rancher.com/products/rancher) and [Red Hat OpenShift](https://www.redhat.com/en/technologies/cloud-computing/openshift).
